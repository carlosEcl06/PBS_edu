# PBS_edu

A hands-on guide to running compute jobs on this shared cluster: PBS basics,
checking node availability, running tools via Apptainer containers, real pitfalls hit
while building an actual pipeline here, and (optionally) orchestrating multi-step
pipelines with Nextflow.

## Pick your language

| Folder | Language |
|---|---|
| [`en/`](en/) | English |
| [`pt/`](pt/) | Português (Brasil) |
| [`fr/`](fr/) | Français |
| [`es/`](es/) | Español |

All four contain the exact same content — pick whichever you're most comfortable
reading. Commands, flags, file paths, and tool names are the same in every version
(they have to be — that's what you actually type); only the explanations and comments
are translated.

Start with that language folder's own `README.md`.
